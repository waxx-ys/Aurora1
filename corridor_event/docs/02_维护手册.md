## 4. 最常改的东西

### 4.1 换女巫契约图

1. 替换 `assets/ui/witch_pact.png`（任意尺寸，程序用 COVERED 铺满）；
2. 重新导入：`Godot --headless --path . --import`；
3. 不用改代码。整张图可点。

> 契约图在 `main.gd` 的 `PACT_TEXTURE_PATH` 定义；想换路径就改这里。

### 4.2 改触发位置

| 内容 | 文件 | 说明 |
| --- | --- | --- |
| 牌阵世界 Z | `tools/build_corridor.gd` 常量 `ZONE_Z` | 改完必须重建 `main.tscn` |
| 触发盒大小 | `scenes/buffer_zone.tscn` → `TriggerArea/CollisionShape3D` | 默认 Box(5.8,3.2,4.2) |
| 动态雾相对位置 | 生成器自动写：`ZONE_Z-16/-1/+2/+12` | 也可以直接改 `main.gd` 的 `fog_*` 导出值 |
| 触发后行为 | `main.gd` → `_begin_pact()` | 0.9s 压雾 → 淡出 → 契约图 |
| 结局区 Z | `tools/build_corridor.gd` 常量 `ENDING_Z` | 默认 2512 |

**改长度时同步清单**：

1. `LENGTH`、`Z_END`、`Z_CENTER`、`ZONE_Z`、`ENDING_Z`；
2. 材质 UV：`floor_stone` / `wall_log` / `ceiling_wood` 的 `uv1_scale` 按新长度；
3. 测试里的碰撞尺寸/触发 Z/结局 Z/10 分钟断言；
4. 截图脚本里的 z 坐标；
5. 文档里的数字。

### 4.3 改翻牌游戏的难度/时间/卡面

文件：`memory_game/scripts/game_config.gd`

- `LEVELS`：三档的 columns/rows/pairs/time_limit/max_mistakes/preview_time/card_size；
- `LEVEL_ORDER`：大厅顺序；
- `CARD_POOL`：卡面 id/名称/lore/art 路径。

改完不用改长廊。玩家进入翻牌后在大厅选难度。

> **不要再在长廊里写死难度**：打开时用 `open_from_command({"view":"menu"})`；不要传 `{"view":"level","level":"3x4"}`。

### 4.4 改翻牌嵌入布局

文件：`scripts/main.gd` → `_build_memory_overlay()`

- `SubViewport.size = Vector2i(1024, 768)`：翻牌游戏原生设计尺寸；
- 容器 `view_h = 720`、`view_w = 1024 * (720/768) = 960`，水平居中；
- 左右 160 px 用契约图做暗色边 + 紫黑细边框；
- 鼠标/键盘由 `SubViewportContainer` 转发；不要在它上面盖透明 Control。

想全屏铺满可改窗口/容器尺寸，但会拉伸 1024×768 布局；不建议。

### 4.5 改过渡节奏

`main.gd`：

| 位置 | 默认 |
| --- | --- |
| 压雾等待 | 0.9 s |
| 淡出到契约图 | 0.55 s |
| 契约图淡入 | 0.7 s |
| 点击后淡出 | 0.5 s |
| 翻牌淡入 | 0.7 s |
| 一局结束自动回廊淡出 | 0.4 s |
| 回到长廊淡入 | 0.8 s |

所有过渡都用 `FadeLayer` 的黑场，统一、不会闪出桌面。

### 4.6 改刻印效果

`main.gd`：

```gdscript
const TRIAL_BLESSING_MULTIPLIER := 1.18
const TRIAL_CURSE_MULTIPLIER := 0.82
const TRIAL_EFFECT_DURATION := 45.0
```

- 成功：`player.apply_trial_effect(1.18, 45)` + HUD “正面刻印”；
- 失败：0.82/45 + “负面刻印”；
- 中途关闭（没有 run_finished）：按失败结算，施加负面刻印。

### 4.7 改结局文本

`main.gd` → `_build_ending_text()`；HUD 面板在 `ui/event_hud.tscn` 的 `EndingPanel`。预留空间在 `scenes/ending_zone.tscn`，中央不要放道具。

### 4.8 改雾

`main.gd` 的“动态雾”导出组；生成器会写入绝对 Z。调参建议：

- 想更浓：`fog_dense_density` 0.22→0.26、`fog_event_density` 0.38→0.44；
- 想更快散：`fog_relief_speed` 1.1→1.6；
- 雾恢复后站在牌阵又变浓：检查 `_fog_relief`；正常情况下玩家在牌阵雾区内会维持常态，离开后才恢复按 Z 计算。
- 远处发黑不是发灰：先提高 `fog_light_color/energy`，不要盲目加密度。

### 4.9 改旧灯/道具密度

`tools/build_corridor.gd` 顶部：

```gdscript
const LANTERN_STEP := 28
const BEAM_STEP := 24
const TALISMAN_STEP := 40
const MOSS_STEP := 50
const BONE_STEP := 37
const CHAIN_STEP := 110
const RAG_STEP := 96
const PLANK_STEP := 108
```

2520 m 下不建议把灯距降到 <20 m（灯数会接近 130，GL 兼容渲染压力大）。

## 7. 故障排查

### 7.1 打开游戏全黑

- 先看 `main.gd` 是否在最开始调用 `hud.set_fade_alpha(0.0)`；HUD 自带的 `FadeRect` 默认是黑色全屏。
- 再看 `FadeLayer` 的 `_fade_rect.visible` 是否为 false。
- 最后看 `PactLayer.visible` / `PactRoot.visible` 是否误开。
- 本次真实踩过：HUD 的黑色 FadeRect 没清零，窗口全黑但日志一切正常。

### 7.2 走到 z=1260 没反应

| 检查 | 方法 |
| --- | --- |
| 玩家是否进 Area | F3 看缓冲=是；瞬移到 (0,0.05,1260) |
| 层/掩码 | TriggerArea mask=2，Player layer=2 |
| 状态 | F3 状态=IDLE？ |
| 是否在翻牌/契约状态 | `MEMORY/PACT` 时不会重复触发 |
| 触发盒是否被改小 | `get_trigger_size()` 纵深 >3 |

### 7.3 契约图不出现

- `PACT_TEXTURE_PATH` 资源是否存在；
- `PactLayer.visible` 与 `PactRoot.visible` 是否都 true；
- 是否卡在淡出 tween（`FadeLayer` 的 modulate）；
- 看日志 `[CorridorMain] pact image · zone entered`。

### 7.4 点击契约图没反应

- 代码同时支持 Control GUI 与 `_unhandled_input` 兜底；检查是否有别的全屏 Control（HUD FadeRect、FadeLayer）盖住；
- `PactRoot.mouse_filter` 必须是 STOP；
- 窗口失焦时点击可能只激活窗口，再点一次。

### 7.5 翻牌游戏打不开 / 一个黑框

- 看 `memory_game/memory_game.tscn` 是否存在；
- 看 `memory_game/art/`、`output/witch-ui/background-*.png`、`hakidame.TTF` 是否齐全；
- 看日志 `[CorridorMain] embedded memory opened`；
- 黑框但无内容：检查 SubViewportContainer 尺寸是否 0，或 `SubViewport` 是否被 `set_corridor_world_visible(false)` 误隐藏（只应隐藏 3D 节点，不应隐藏 CanvasLayer）。

### 7.6 翻牌游戏鼠标点不动

- `SubViewportContainer.mouse_filter=STOP`；
- 容器没有被透明 Control 覆盖（帧 Panel 必须 mouse_filter IGNORE）；
- 不要给 SubViewport 设 `gui_disable_input=true`；
- 本次已在窗口模式下验证：鼠标可悬停 PactRoot，可点击 2×3 卡牌并开始游戏。

### 7.7 翻牌游戏无法返回

- 翻牌右上角 × / Esc；`main.gd` 在 MEMORY 状态也监听 Esc 兜底；
- 如果按 Esc 只释放鼠标，检查 `_state` 是否卡在 MEMORY（F3）；
- 一局结束：`run_finished` → 隐藏翻牌结算页 → `_return_from_memory()`；
- 中途退出：`close_requested` → 判失败 → 回廊 + 负面刻印；
- 如果结束后还停留在翻牌结算页，检查 `_on_memory_run_finished()` 是否调用了 `_return_from_memory()`。

### 7.8 难度被固定 / 玩家不能选

- 打开时必须 `open_from_command({"view":"menu"})`；
- 不要传 `"view":"level","level":"3x4"`；
- 测试里断言 `_level_id==""` 且 `_difficulty_cards.size()==3`。

### 7.9 翻牌结束后雾不散

- `_return_from_memory()` 必须调用 `_set_fog_relief()`；
- 玩家 z<8 会自动清除 relief；
- 60 秒后且玩家离开牌阵雾区，relief 才失效；站在区内会继续保持常态。

### 7.10 结局区不显示文本

- EndingZone 是否存在（F3 / 测试）；
- `collision_mask=2`，玩家组 `player`；
- HUD `EndingPanel` 路径；
- 玩家是否在 z≈2512。

### 7.11 长走廊卡顿

- 1650 个节点 + 约 90 盏 OmniLight 是当前规模；降低 `LANTERN_STEP` 的反面（增大间距）或减少道具间距；
- 翻牌时已隐藏 3D；如果仍卡，检查是否有旧 EventBridge/UDP 进程；
- 删除 `.godot` 重新导入，确认贴图是 2048 而不是 4K。

### 7.12 改完地图后贴图拉伸/墙碰撞错位

- 材质 `uv1_scale` 必须随 LENGTH 改；
- 碰撞盒长度必须同步 `LENGTH`；
- 触发/结局 Z 必须同步；
- 重新生成 `main.tscn`，不要手改生成物。
